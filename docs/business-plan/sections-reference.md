## Content Patterns

### Data Card Pattern
Used for: Key statistics, metrics

```html
<div class="data-grid">
    <div class="data-card">
        <h4>Label</h4>
        <div class="value">Value</div>
        <div class="stat-label">Description</div>
    </div>
</div>
```

### Table Pattern
Used for: Comparisons, breakdowns, timelines

```html
<table style='width:100%; border-collapse: collapse; margin: 1rem 0;'>
    <tr style='border-bottom: 1px solid #3d6b4f;'>
        <td style='padding: 0.5rem;'><strong>Header</strong></td>
        <td style='padding: 0.5rem; text-align: right;'><strong>Value</strong></td>
    </tr>
    <tr>
        <td style='padding: 0.5rem;'>Row</td>
        <td style='padding: 0.5rem; text-align: right;'>Data</td>
    </tr>
</table>
```

### List Pattern
Used for: Features, benefits, requirements

```html
<ul>
    <li><strong>Bold label:</strong> Description text</li>
</ul>
```
